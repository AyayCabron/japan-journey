# Japan Journey

Plataforma para planejamento de viagens ao Japão, reunindo roteiros, mapas, metas financeiras, despesas, cotações, clima e pesquisa de passagens.

## Estrutura

apps/
  web/
  api/
packages/
docs/
supabase/
archive/

## Aplicações

- apps/web: aplicação React e TypeScript.
- apps/api: API Python executada em Cloudflare Workers.

## Serviços

- Cloudflare Pages
- Cloudflare Workers
- Supabase
- APIs externas de mapas, câmbio, clima e viagens

## Desenvolvimento

Os requisitos e comandos de desenvolvimento serão documentados conforme cada aplicação for adicionada.
