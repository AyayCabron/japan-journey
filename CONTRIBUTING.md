# Contributing

## Branch Strategy

- feat/<feature-name>
- fix/<bug-name>
- refactor/<module-name>
- docs/<topic>
- chore/<task>

## Commit Convention

- feat
- fix
- refactor
- docs
- test
- chore
- ci

Examples

feat(web): add dashboard
fix(api): validate jwt
docs: update architecture

## Code Standards

- Use English for code.
- Use Portuguese for user documentation.
- Keep commits small.
- Avoid committing generated files.
- Do not commit secrets or credentials.
